# Test Tracker Frontend

Cartella per il frontend dell'applicazione Test Tracker, costruita con React, Vite e Tailwind CSS.



- **React** (^19.2.5) - UI Framework
- **Vite** (^8.0.9) - Build tool e dev server
- **Tailwind CSS** (^4.2.4) - Utility-first CSS framework
- **shadcn/ui** - Componenti UI di alta qualità
- **React Router DOM** (^7.14.1) - Routing
- **Axios** (^1.15.1) - HTTP Client
- **Material-UI** (^9.0.0) - Componenti aggiuntivi
- **Lucide React** - Icone

## 📦 Script Disponibili

### Development
```bash
npm run dev      # Avvia il server di sviluppo (Vite)
```
